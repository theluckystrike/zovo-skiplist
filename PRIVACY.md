# Privacy disclosure

Zovo SkipList stores personal bookmarks, category profiles, podcast rules, listening-time statistics, and a cached license result in Chrome extension storage.

The extension does not sell data, use analytics, transmit browsing history, or read/write the SponsorBlock community database. It runs only on supported YouTube pages. License activation sends the entered license key to Zovo's Supabase verification function; no video URL, title, bookmark, profile, rule, or listening statistic is included.

Users can export or import their personal settings and remove all stored data by uninstalling the extension or clearing its extension storage.
